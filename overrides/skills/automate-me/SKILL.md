# Automate me

Use the user's stated preferences, the current conversation and explicitly
available relevant examples. Do not mine unrelated chat history. Infer only
habits supported by examples; ask for a genuinely consequential missing preference.

Look for an existing requested skill before creating another. Use the current
client's documented skill location and authoring capability. Preserve user scope
and client permissions. Separate reusable choices from one-off task details.

Create a concise skill with meaningful name and description, scoped triggers,
and references only where they help. Validate its frontmatter and supporting
scripts. Explain what it changes and which observations justify it.
