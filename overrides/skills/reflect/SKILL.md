# Reflect

Scope the reflection to the current task or explicitly supplied run. Read its
artifacts, checks and available transcript. If no transcript is exposed, state
that the reflection uses only visible context and recorded artifacts.

Use the judgment, tooling and divergent reviewer references to examine different
failure modes. Run independent readers only if available and permitted; otherwise
evaluate the perspectives yourself and label the limitation.
Verify proposed lessons against the evidence. Prefer one structural improvement
that prevents a demonstrated failure over a list of generic rules.

Return accepted improvements, rejected suggestions and unresolved questions.
Editing skills or publishing changes is a separate action unless already included
in the request. Preserve unrelated preferences and instructions.
