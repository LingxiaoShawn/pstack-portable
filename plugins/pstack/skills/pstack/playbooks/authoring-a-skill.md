### Authoring a skill
Use an available skill-creator or the documented Agent Skills format. Preserve
scope and current user instructions. Use the current client's documented skill
location, valid frontmatter, short discovery description and relevant references.

Check supporting files resolve after installation, run any new helper scripts,
and validate the package. When behavioral evaluation is warranted and independent
agents are available and permitted, test on a realistic task in an isolated
workspace. Otherwise state which validation was actually performed.
