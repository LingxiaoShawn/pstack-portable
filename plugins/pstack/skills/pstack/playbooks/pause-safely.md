### Pause safely
Finish or stop the active unit at a recoverable boundary. Preserve all uncommitted
work. Record branch/worktree, current changes, last successful verification,
unresolved risks, outstanding workers and the exact next action in a local
checkpoint. Do not commit or publish unrelated work.

Distinguish running external jobs from work that stops with this session. Never
claim a local agent survives client shutdown without an actual host capability.
Return the checkpoint location and the essential resumption instruction.
