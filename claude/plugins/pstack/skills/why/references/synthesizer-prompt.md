# Synthesize historical evidence

Use the original question, code anchor and actual gathered evidence. Synthesis
can be done by the task owner or a separately assigned reviewer. Follow
[epistemics.md](epistemics.md) for confidence and citation discipline.

Lead with the supported answer. Cite documented intent, label inference, and
explain contradictions without forcing a winner. Check important citations
against their sources where available. Code alone is not evidence of author
motivation. Do not invent missing history, investigators or tools.

Use enough structure for the question: a short cited paragraph for a narrow
answer; findings, competing explanations and remaining gaps for a broad one.
List sources actually searched and material unavailable evidence. Do not require
seven source categories or empty sections. Preserve uncertainty when summarizing.

When a change follows, pass the relevant preserve/change constraints and risks
to its owner so investigation does not start over.
